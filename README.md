# Steady Node firmware updates

Public distribution repository for approved, signed Steady Node V2 updates.

Stable manifest: https://micromarty.github.io/SN_2U_UpDate/latest.json

No firmware release has been published yet. Firmware source code and private signing keys do not belong in this repository.

Each release contains immutable Slot A and Slot B SUN2 files. The local device browser checks the manifest, compares versions and asks before installing. The device verifies the SUN2 signature.
